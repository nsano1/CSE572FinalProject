# CSE572FinalProject

## Project Overview
This project is part of the CSE572 course and focuses on analyzing and modeling data across various domains, including education and policy simulation. The goal is to explore trends, perform data analysis, and create predictive models using datasets spanning from 1980 to 2020.

## Repository Structure
- **5category_5model.ipynb**: Implements models for analyzing five categories of data.
- **education.ipynb**: Focuses on education-related data analysis.
- **exploratory_data_analysis.ipynb**: Contains exploratory data analysis (EDA) for the datasets.
- **factoring_education.ipynb**: Examines factors influencing education metrics.
- **InteractiveMappings.ipynb**: Creates interactive visualizations and mappings.
- **policy_simulation.ipynb**: Simulates policies based on the analyzed data.
- **dataset_1980_2020.csv**: The primary dataset containing data from 1980 to 2020.
- **education_1980_2019.csv**: A dataset specifically focused on education metrics.
- **README.md**: This file, providing an overview of the project.


## Datasets
dataset_1980_2020.csv: Comprehensive dataset for analysis.
education_1980_2019.csv: Focused on education-related metrics.


## Goals
Perform exploratory data analysis to uncover trends and patterns.
Build predictive models for future trends across multiple domains.
Create interactive visualizations to enhance data exploration.
Simulate policies and evaluate their potential impact.
